# Project Repository Overview

This repository contains all the files, scripts, and notebooks accumulated throughout the development of the diploma thesis: **Analysis of Multiple Myelomas in Dual-Energy CT Based Vertebral Data**.

---

## Important Directory Notice

*   **`_DP_FILES_` (Main Directory):** 
    This folder serves as the core of the project. It contains all the finalized, clean, and essential source codes, main extraction scripts, and final analysis notebooks. If you are looking for the primary deliverables of this thesis, please navigate directly to this folder.

*   **Root Directory & Other Folders:** 
    All other files outside the `_DP_FILES_` folder represent the complete development history. These include various utility helper scripts, preliminary experiments, test analyses, and temporary scratchpad files ("mess scripts") used during the research and development phase. 

For a detailed description of the main source files and how to run them, please refer to the dedicated `README.md` located inside the **`_DP_FILES_`** directory.

---

## Environment & Dependencies

*   **`requirements.txt`:** 
    Located in this directory, this file lists all the Python libraries and packages required to run the project files (including those in the `_DP_FILES_` folder).
